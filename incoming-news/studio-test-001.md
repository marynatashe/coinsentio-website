## 简体中文

CoinSentio 正在测试独立新闻制作系统。编辑人员可以在 GitHub 云端建立新闻内容，经过审核后，由 Python 程序转换成 Markdown 文件，再交由网站的定时新闻导入系统处理。这篇文章只用于测试数据格式及制作流程，不代表任何加密货币市场事件。
